# SPECTRONA Round 2 CTF Writeups

Solved by Aayush Upadhyay

## Overview

This repository contains writeups for various challenges from SPECTRONA Round 2 CTF competition. Each challenge writeup includes the flag, challenge overview, detailed solution steps, and key takeaways.

## Challenges

### Web Security
- **Project Chimera** - JWT Authentication and SQL Injection (`SPECTRONA_Project_Chimera/`)

### Cryptography & Reverse Engineering
- **FERIC** - WebAssembly Reverse Engineering (`FERIC/`)
- **PATINA** - WebAssembly Analysis (`PATINA/`)

### Steganography & Forensics
- **Spectrona CTF CTF CTF** - Multi-stage steganography with Blender glyphs (`Spectrona_CTF_CTF_CTF/`)
- **Dead Drop** - LSB Steganography (`DEAD_DROP/`)
- **The Final Move** - Chess PGN Analysis (`The_Final_Move/`)

### OSINT
- **Ashes Test** - Aircraft ICAO Type Identification (`Ashes_Test/`)
- **Out Of CTRL** - Cryptocurrency Wallet Compromise Investigation (`Out_Of_CTRL/`)

### Linux & Forensics
- **Linux Labyrinth** - Linux Command-Line Investigation (`LINUX_LABYRINTH/`)
- **The Quiet Inode** - Forensic Analysis (`THE_QUIET_INODE/`)
- **Linux Linux What's This Sudden Influx** - Git and Browser Forensics (`Linux_Linux_what's_this_sudden_influx/`)

## Repository Structure

Each challenge directory contains:
- Challenge writeup (markdown file)
- Challenge files (where applicable)
- Solution scripts (where applicable)

All writeups follow a consistent format:
1. Title
2. Solved by attribution
